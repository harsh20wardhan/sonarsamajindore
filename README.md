# सोनार समाज ट्रस्ट, इंदौर (Sonar Samaj Trust, Indore)

Official website for **सोनार समाज ट्रस्ट, इंदौर** (Domain: [sonarsamaj.com](https://sonarsamaj.com)).

## Features
- **Design System**: Modern community UI inspired by Merasamaj with clean typography and warm heritage colors.
- **Sections**:
  - Hero with impact metrics ribbon (500+ active members, 70+ awards, 3000+ activities, 7000+ families)
  - About Us & Objectives
  - Good Deeds (6 pillars: Education, Healthcare, Financial aid, Divyang assistance, Employment, Blood donation)
  - Executive Committee profiles
  - Upcoming Events (Maha Aarti, Gurupurnima, Blood donation) & Latest News
  - Donation with Bank Account & UPI QR Scanner
  - Membership Registration (with WhatsApp direct integration)
  - Interactive Photo Gallery with full Lightbox
  - Contact details, Google Map reference, and Netlify contact form
  - Multi-lingual language switcher (Marathi, Hindi, English)
  - Floating WhatsApp helpline

## Deployment
This project is configured for one-click deployment on Netlify or AWS S3 + CloudFront.
- **Publish Directory**: `.` (Root)
- **Primary file**: `index.html`
